rpi-rgb-led-matrix as built into hako
=====================================

hako drives its 64x64 LED panel with rpi-rgb-led-matrix by Henner Zeller,
licensed under the GNU General Public License version 2 (COPYING.txt).

This folder is the complete corresponding source for the copy on every hako:

  rpi-rgb-led-matrix-14464b3.tar.gz
    Upstream https://github.com/hzeller/rpi-rgb-led-matrix at commit
    14464b3ad8974665f75a3c82355cf872311fec21 (2026-10-10), unmodified.
    SHA-256 7c322e7d0d2df56fb2ad62a26673f3d75d60eed64ced6f42d4d8242fea1db8f9

Build
-----
On a Raspberry Pi 3 Model A+ running Raspberry Pi OS Lite (Bookworm, 32-bit):

  sudo apt-get install -y --no-install-recommends \
      python3 python3-dev python3-pip build-essential cmake cython3
  tar xzf rpi-rgb-led-matrix-14464b3.tar.gz
  sudo pip3 install --break-system-packages ./rpi-rgb-led-matrix-14464b3

That builds the C++ library and the Python binding ("rgbmatrix") with the
default build configuration (no changes to config.mk or CMake options).

Runtime options
---------------
hako sets these when it opens the panel (they are not build settings, but
they are what you need to reproduce how hako runs it):

  rows=64 cols=64 chain_length=1 parallel=1
  hardware_mapping=adafruit-hat-pwm  panel_type=FM6126A
  row_address_type=0 multiplexing=0 scan_mode=1
  pwm_bits=8 gpio_slowdown=2 limit_refresh_rate_hz=100 brightness=60
  drop_privileges=False
